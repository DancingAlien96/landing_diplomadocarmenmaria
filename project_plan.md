# Diplomado en Enfermería Básica — Landing Page

## 1. Project Description
Landing page corta, moderna y profesional para promocionar el **Diplomado en Enfermería Básica con enfoque en Cuidado Domiciliar**.

- Posicionamiento: formación básica y práctica, NO una carrera profesional de enfermería.
- Audiencia: personas interesadas en aprender cuidados básicos de enfermería para aplicar en el hogar.
- Valor principal: adquirir conocimientos esenciales con formación práctica y docente especializada.
- Objetivo único de conversión: que el visitante contacte por **WhatsApp** para solicitar información e inscribirse.

## 2. Page Structure
- `/` — Landing page (una sola página, con navegación por anclas internas)
  - #programa — ¿Qué es?
  - #contenidos — ¿Qué aprenderás?
  - #practica — Formación práctica
  - #preguntas — Preguntas comunes
  - #informacion — Información del diplomado
  - #inscripcion — Llamado a la acción final

## 3. Core Features
- [x] Hero visual de alto impacto con etiqueta (40 horas), título, subtítulo y CTA a WhatsApp.
- [x] Sección "¿Qué es?" breve a dos columnas con imagen.
- [x] Sección "¿Qué aprenderás?" con 6 tarjetas de contenido + iconos lineales.
- [x] Sección "Formación práctica" con línea de tiempo (horizontal en desktop, vertical en móvil).
- [x] Sección "Escenarios de clase" con imágenes de ambiente de estudio y técnicas de aprendizaje.
- [x] Sección "Información del diplomado" con tarjetas limpias.
- [x] Sección "Preguntas comunes" con acordeón desplegable.
- [x] CTA final con panel azul institucional contenido + botón grande a WhatsApp.
- [x] Botón flotante de WhatsApp siempre visible (especialmente en móvil).
- [x] Menú de navegación responsive (desktop + hamburguesa en móvil).
- [x] Animaciones sutiles de aparición al hacer scroll.
- [x] Estética minimalista y predominantemente blanca, con azul institucional y dorado como acentos.
- [x] Imágenes sin personal uniformado de enfermería (curso particular de formación básica).
